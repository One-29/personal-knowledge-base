# 高等数学演示指南

| 字段 | 内容 |
|---|---|
| 演示库 | 大一上高等数学演示库 |
| 文档 | 8 篇 Markdown 笔记 |
| 覆盖范围 | 常见高等数学上册（大一上）的函数、极限、连续、导数、积分、积分应用、常微分方程 |
| 适用功能 | 普通问答、引用溯源、工作流、关联图 |
| 校准模型 | `BAAI/bge-m3`，1024 维 |

## 1. 加载或恢复演示库

先在 `.env` 中配置 Embedding，再从项目根目录执行；脚本会自动启动 Ubuntu WSL2 内的独立 Docker Engine 和 `knowbase-pg`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\load-calculus-demo.ps1
```

加载器读取 `demo/calculus/*.md`，先用临时名称创建知识库并逐篇切块、向量化。只有全部 8 篇文档都进入 `ready`，才在同一数据库事务中删除旧的同名演示库并切换正式名称。中途失败时会清理临时库并保留原来的正式演示库。

重新加载演示库或更新、删除文档后，旧知识块的数据库 ID 会失效。浏览器保存的历史回答同时保存了回答生成时的文档标题、原文块和字符区间；点击这类旧引用时，右侧核对栏会显示“回答时引用快照”，并明确提示当前原文已经更新或删除。当前回答仍优先读取数据库中的最新引用详情。

加载器禁止向 `knowbase_test`、`knowbase_eval` 以及名称以 `_test` 或 `_eval` 结尾的数据库写入，避免演示数据破坏自动测试或质量评估环境。

## 2. 普通问答与引用演示

在“问答”中选择“大一上高等数学演示库”，可以依次提问：

1. 数列极限定义中的 ε 和 N 分别表示什么？
2. 为什么可导一定连续，而连续不一定可导？请给出反例。
3. 怎样用导数符号表判断函数的单调区间和极值？
4. 牛顿—莱布尼茨公式如何把导数、原函数和定积分联系起来？
5. 一阶线性微分方程如何使用积分因子求解？

回答中的 `[n]` 可以点击。演示时把两到三个引用钉在右侧“原文核对”栏，说明回答正文、来源文档和原文字符区间之间的对应关系。

还可以先问“什么是导数”，再追问“那它为什么能判断单调性”。第二问会携带浏览器保存的历史，由后端改写为自包含检索问题。

## 3. 工作流与并发演示

在“工作流”中选择同一个知识库，执行：

> 梳理极限、连续、导数和积分之间的逻辑关系，分别给出核心定义、关键定理和典型计算方法，并标明出处。

工作流会先规划，再顺序执行多个子问题，最后统一整理引用编号。工作流运行期间切回“问答”，再提出一个普通问题，可以看到两个入口并发执行并各自返回。每类入口在同一页面中各允许一个在途请求。

请求开始时会固定会话 ID。执行期间即使切换到另一个会话，结果仍保存到发起请求时的会话；切回原会话即可查看。如果原会话已经被删除，结果不会写入本地记录，界面会提示本次结果未保存，也不会复活已删除会话。

## 4. 关联图阈值演示

八篇笔记刻意形成几组强弱不同的语义联系：极限与连续、导数与中值定理、不定积分与定积分、定积分与几何应用，以及导数/积分与微分方程之间的桥接关系。

使用 `BAAI/bge-m3` 对当前语料实际向量化后，四档阈值结果为：

| 下拉选项 | 最低相似度 | 节点 | 边 | 观察重点 |
|---|---:|---:|---:|---|
| 宽松 | 0.60 | 8 | 23 | 8 个节点全部连通，接近完全图（23/28 条可能边） |
| 标准 | 0.68 | 8 | 18 | 8 个节点仍全部连通，主题分组开始清晰 |
| 清晰 | 0.72 | 8 | 10 | 前 7 篇形成连通分量，常微分方程成为孤立节点 |
| 核心关系 | 0.76 | 8 | 1 | 仅保留最强的“函数与极限—连续性”连接 |

节点数始终为 8，因为接口也会返回没有连边的孤立文档节点；它不表示八篇文档在每档阈值下都互相连通。切换下拉框后，前端会重新请求关联图并重新布局。可以悬停节点查看标题、块数、字数及相连文档，再拖动节点展示力导向布局。

相似度阈值依赖 Embedding 模型。即使模型名与维度相同，服务商实现、模型版本或归一化方式变化也可能改变边数，因此应以加载器的实际输出为准。更换模型或维度后需要重新导入演示库并重新校准阈值；加载器会检查四档边数是否逐档减少，如果不满足就以非零状态退出并提示重新校准。

## 5. 演示数据的边界

演示库保存在日常 `knowbase` 中，所以会出现在界面，也会在选择“全部知识库”时参与检索。它的用途是提供可重复的公开样例，不应放入个人隐私资料。

pytest 使用独立的 `knowbase_test`；质量评估使用 `knowbase_eval` 和 `data/eval-storage`。后两者不会出现在日常界面，也不会进入日常全库检索。
