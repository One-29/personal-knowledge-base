# Python 数据模型与常用容器

Python 对象由身份、类型和值组成。变量保存对象引用，赋值语句通常不会复制对象。两个变量引用同一可变列表时，通过其中一个变量修改内容，另一个变量也能观察到变化。`is` 比较对象身份，`==` 调用相等性协议比较值；除 `None` 等单例判断外，业务值通常使用 `==`。

## 可变对象、浅拷贝与深拷贝

列表、字典和集合是可变容器，元组与字符串不可变。浅拷贝创建新的外层容器，但内部元素仍是原对象引用，因此嵌套列表的修改可能同时出现在副本中。`copy.deepcopy` 递归复制对象图，并用备忘录处理共享引用和循环结构；它成本更高，也不一定适合文件句柄、连接等外部资源。

## 字典、集合与哈希

字典和集合基于哈希表，平均查找、插入和删除复杂度为 O(1)。键必须可哈希：对象的哈希值在生命周期内保持稳定，并且相等对象必须具有相同哈希值。因此含可变元素的列表不能作字典键，而只含可哈希元素的元组可以。哈希冲突由内部探测策略解决，最坏情况并不保证 O(1)。现代 Python 字典保持插入顺序，但顺序性质不改变键唯一的语义。

## 迭代协议与上下文管理器

`iter(obj)` 获取迭代器，反复调用 `next` 取得元素，耗尽时抛出 `StopIteration`。可迭代对象可以每次产生新迭代器，迭代器自身通常只能向前消费一次。上下文管理器实现 `__enter__` 与 `__exit__`，`with` 语句确保正常返回或抛异常时都执行清理。文件对象用这一协议可靠关闭资源，避免把释放动作散落在多个分支中。
